# Conception Record

This repository contains a dated record of an original architectural concept,
authored by Premkumar Thiagarajan. It is committed to version control to
establish a timestamped record of conception and authorship.

This repository is not a patent filing.

If this repository is private, it currently serves only as a private,
timestamped conception record for the author's own reference.

If this repository is public, its public availability from the date shown in
the commit history is intended to also serve as a defensive disclosure —
i.e., a deliberate act of making the described concept publicly known, so
that it may be used freely by anyone and is not exclusively patentable by
any party, including the author.

See `conception-record-homogeneous-capability-extension.md` for the claim.
